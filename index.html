Compliance Breakdown

Compliant = flagged, actioned in Betti/Dash, and (Homeowner orgs) the Genesys / SF step completed. Process Non-Compliance = flagged and actioned in Betti/Dash, but the SF / Genesys step was not completed; applies to the Homeowner orgs only. Non-Compliant = Betti/Dash was not updated; this is the legal-risk bucket. Not matchable = no SP / consumer ID on the transcript, so it cannot be traced; excluded from all rates.

    Detail Table

    Follows the top-line filters (date, domain, director, manager, rep). Call-level and SF-case-level detail (call id, case number) comes from the unified query and is not embedded here.

    Notes
    • Date logic: the voice transcript call date is the date filter. Non-voice channels (chat / email) will need to default to the SF Deletion case created date; this extract covers voice transcripts only.
    • Multiple IDs per call: a call counts as actioned if any SP / consumer ID on it was actioned.
    • Snapshots: Betti/Dash flags for homeowners (and the Pro Care profile flag) are current-state snapshots, so someone already DNC before the call can show as actioned. Pro Sales uses status history timestamps (action must follow call start).
    • Grain: embedded data is week × domain × manager. Rep detail covers the 150 reps with the most non-compliant + process non-compliant calls over the full period and cannot be cut by week.
