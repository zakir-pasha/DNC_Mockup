Definitions

  • DNC Non-Compliance Rate = % of calls flagged as DNC that were never actioned in Betti or Dash.
  • DNC Process Non-Compliance = % of calls flagged as DNC that were actioned in Betti or Dash, but the required process step was skipped: the Genesys DNC disposition and/or SF DNC form (Homeowner Success), or the SF DNC form / Quick Action case (Support + Services Pro). Homeowner orgs only.
  • Compliant = flagged and every step of the domain's funnel was completed.

Notes
  • Date logic: the voice transcript call date is the date filter (from and to dates are both inclusive). Non-voice channels (chat / email) will need to default to the SF Deletion case created date; this extract covers voice transcripts only.
  • Multiple IDs per call: a call counts as actioned if any SP / consumer ID on it was actioned.
  • Snapshots: Betti/Dash flags for homeowners (and the Pro Care profile flag) are current-state snapshots, so someone already DNC before the call can show as actioned. Pro Sales uses status history timestamps (the status change must follow the call start).
  • Team in the process table is the domain the rep's calls belong to; director / manager come from the rep's current Betti reporting line.
  • Data gap: no Homeowner Success SF DNC forms are matched to calls before Jul 27, so earlier Homeowner Success calls can only land in Process Non-Compliance or Non-Compliant.
  • Grain: embedded data is day × rep × domain, so every filter combination above is exact.
