Definitions

  • DNC Non-Compliance Rate = % of calls flagged as DNC that were never actioned in Betti or Dash.
  • Action Completion = flag set and the action was taken in Betti / Dash. The Salesforce / Genesys step is not necessarily complete.
  • Fully Compliant (whole funnel) = flagged and every step of the domain's funnel was completed end to end. For Pro Sales and Pro Care, which have no intermediate step, this equals Action Completion.
  • DNC Process Non-Compliance = flagged calls actioned in Betti or Dash, but the required process step was skipped: the Genesys DNC disposition and/or SF DNC form (Homeowner Success), or the SF DNC form / Quick Action case (Support + Services Pro). Homeowner orgs only.

Notes
  • Date logic: the voice transcript call date is the date filter (from and to dates are both inclusive). Non-voice channels (chat / email / SMS) are not in V1; this extract covers voice transcripts only.
  • Multiple IDs per call: a call counts as actioned if any SP / consumer ID on it was actioned. The ID-level view shows every ID so you can see which accounts still need DNC applied.
  • Same-phone accounts: for homeowner calls the ID-level view also lists other Betti accounts sharing a phone number with the person on the call (phones shared by more than 25 accounts are ignored as placeholders). These rows are for visibility and do not change call-level compliance.
  • Snapshots: Betti/Dash flags for homeowners (and the Pro Care profile flag) are current-state snapshots, so someone already DNC before the call can show as actioned. Pro Sales uses status history timestamps (the status change must follow the call start).
  • Team / reporting line: Team is the domain the rep's calls belong to. Director, manager and rep come from the UKG-fed daily roster (rpt.reports.d_rep_user_roster) as of the call date.
  • Start date: the dashboard starts Aug 1, 2026. The Salesforce "DNC/Unsubscribe" case disposition did not exist before Jul 27, so earlier SF DNC forms cannot be matched to calls.
  • Grain: the data is one row per DNC-flagged call (plus one row per call × ID), so every filter combination above is exact.
