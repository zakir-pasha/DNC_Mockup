Compliance Breakdown

Compliant = the complete required funnel was documented and the downstream DNC action was completed. Process Non-Compliance applies only to Homeowner Success and Homeowner Support + Services Pro: the Betti/Dash action is present, but one or more required documentation steps are missing (Genesys and/or Salesforce, depending on the domain). Non-Compliant = the final downstream DNC action was not found. Calls with no SP / consumer ID on the transcript are excluded.

Notes
  • Date logic: the voice transcript call date is the date filter. Non-voice channels (chat / email) will need to default to the SF Deletion case created date; this extract covers voice transcripts only.
  • Scope: only calls with at least one SP / consumer ID on the transcript are included; calls with no ID are excluded.
  • Multiple IDs per call: a call counts as actioned if any SP / consumer ID on it was actioned.
  • Snapshots: Betti/Dash flags for homeowners (and the Pro Care profile flag) are current-state snapshots, so someone already DNC before the call can show as actioned. Pro Sales uses status history timestamps (action must follow call start).
  • Mock-data grain: this prototype embeds weekly manager-level aggregates. The connected call-level query supports the daily filters and the detailed process view.
